# EXTERNAL_LEDGER — public sources → `skills-v2/`

Phase 2.5 harvest. The best rules and gotchas from mature public skill sets, official docs and
official samples, absorbed paraphrased in our voice with attribution (STANDARDS §7, owner decision
M-2). Nothing is vendored wholesale. Never more than 2 consecutive lines verbatim from any source;
no external code landed, only the rules.

Row format, classes and DROP rules follow `handoff/work/HARVEST_LEDGER.md`. One extra class:

| Class | Meaning |
|---|---|
| CONFLICT | Contradicts a kit decision (STANDARDS §1 or the brief). Kit wins. Recorded with the reason, then dropped, unless the destination is the Phase 2.6 audit trail (`existing-projects.md`, `module-graph.md`, `navigation.md`) where the overruled position must stay visible. |

Evidence is always a source URL plus license, or `UNVERIFIED` with the reason. Full per-group
Findings live in `handoff/work/external-notes/<group>.md`; the unified Findings are at the bottom
of this file.
