## Findings

### Top 10 rows by kit value
1. CMP-30 - Nav3 ViewModels are Activity-scoped unless both entry decorators are set, directly contradicts the one-owner intuition and breaks per-screen state.
2. CMP-57 - Kotlin exceptions die silently or terminate Swift without Throws, the single most crash-prone interop default in the harvest.
3. CMP-41 - common viewModel needs an explicit initializer off JVM, a compile wall every first CMP screen hits.
4. CMP-37 plus CMP-42 - Main-immediate is missing on desktop for both lifecycle scope and viewModelScope, one dependency fixes both.
5. CMP-99 plus CMP-100 - AGP 9 forces the android-kmp-library plugin and a separate androidApp module, the kit convention-plugins have no such rule yet.
6. CMP-77 - preview tooling dependency changes shape under the android-kmp-library plugin, easy to mis-copy from old snippets.
7. CMP-08 - missing script-less values directory throws at runtime for multi-script languages, a release-blocking locale gotcha.
8. CMP-84 - desktop packager never infers JDK modules, failures appear only at runtime in the shipped binary.
9. CMP-55 - SKIE Flow limits around exceptions casts and custom types bound what the kit may expose to Swift.
10. CMP-86 - unsigned macOS builds present as damaged, signing plus notarization is a distribution gate not an option.
